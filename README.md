# NOVA — Curated Essentials

A redesigned React + TypeScript e-commerce portfolio project.

## Highlights
- Responsive modern storefront
- Product browsing, categories, search and product details
- Cart and wishlist flows with Redux Toolkit
- Authentication modal and protected routes
- Dark / light mode
- Toast feedback
- Mobile-first navigation
- DummyJSON product API integration

## Tech Stack
React, TypeScript, Vite, React Router, Redux Toolkit, Tailwind CSS, React Icons.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
